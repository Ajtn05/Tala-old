Tala 2.1.0 improves file-import processing and fixes native dependency setup in CI.

### Changes

- Skip inference for windows containing only exact digital silence. Quiet speech
  still uses the same verified Large v3 Turbo model and recognition settings.
- Decode one audio window ahead while transcribing the current window, with
  bounded memory use and preserved sample order and timestamps.
- Recover missing PortAudio and Whisper source files from build-only cache
  restores, and cache complete native dependency trees in CI.
- Fix macOS cache recovery with a portable copy operation that preserves existing
  files. Add regression checks using Apple's system tools and Linux setup paths.
- Add repeatable real-inference transcript/timestamp comparisons and thread
  timing experiments.

### Performance and accuracy

An Apple M5 benchmark reduced elapsed time from 14.68 to 10.76 seconds (26.7%) for
a synthetic 71-second recording containing a full 30-second window of digital
silence. Speech text and timestamps matched the original output exactly; false
text generated during digital silence was removed. Continuous speech showed no
meaningful throughput gain. Results depend on the recording and hardware.

The existing model, automatic multilingual detection, and four-thread default
remain. See the [benchmark report](https://github.com/Ajtn05/Tala/blob/v2.1.0/docs/IMPORT_PERFORMANCE.md)
for the tested inputs and limitations.

### Downloads and setup

- **macOS:** `Tala.dmg` for Apple Silicon, macOS 14.2 or later.
- **Linux:** `tala-linux-x86_64.tar.gz`, built on Ubuntu 24.04 x86_64.
- **Verification:** `SHA256SUMS.txt` contains checksums for both packages.

The transcription model is not bundled. New installations must download and
verify it through macOS Settings or `./tala --ensure-model` on Linux. Compatible
existing models are reused in place. File imports require FFmpeg and ffprobe;
URL imports additionally require yt-dlp. Models and transcripts stay outside
the application bundle.
