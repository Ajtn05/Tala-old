Tala 2.2.0 refreshes the desktop workspace and makes file and link imports easier
to configure and follow.

### Desktop workspace

- Start recordings, review files and links, and follow the queue from the home
  screen, with recent sessions and lists that grow with the window.
- Refreshed navigation, rounded surfaces, a bundled Manrope font, and six saved
  color schemes with system, light, or dark appearance.
- Interface labels no longer highlight when dragged. Transcript text, titles,
  metadata, and editable fields remain selectable.

### File and link imports

- Select start/end times for each file or link, including milliseconds. Only the
  selected audio is transcribed; transcript and subtitle timestamps keep their
  original media times. Link imports still download the complete source.
- Rename a transcript after **Fetch details**, before adding it to the queue.
  Chosen names survive metadata refreshes, retries, and restarts.
- Follow live download progress in the home queue, full Queue, and CLI, with
  transferred bytes, percentage, speed, and ETA when available. Estimated totals
  are marked `~`; unknown totals use an activity indicator.
- Optional yt-dlp sign-in helper opens the source site and uses a selected browser
  session. Zen profiles are supported. Dia and unlisted browsers can use an
  exported Netscape `cookies.txt` file and a copyable sign-in URL; automatic Dia
  cookie extraction is not included. Original cookie files are preserved.

### CLI

- Add `--start` and `--end` to select an import interval, and
  `--cookies-from-browser`, `--browser-profile`, or `--cookies` for signed-in links.
- Terminal progress bars cover imports and recordings. `--progress=auto`,
  `always`, or `never` controls the display. Redirected progress uses occasional
  plain lines on stderr; stdout remains available for transcript output.

### Downloads and setup

- **macOS:** `Tala.dmg` for Apple Silicon, macOS 14.2 or later.
- **Linux:** `tala-linux-x86_64.tar.gz`, built on Ubuntu 24.04 x86_64.
- **Verification:** `SHA256SUMS.txt` contains checksums for both packages.

The transcription model is not bundled. New installations must download and
verify it through macOS Settings or `./tala --ensure-model` on Linux. Compatible
existing models are reused in place. File imports require FFmpeg and ffprobe;
URL imports additionally require a current yt-dlp. Sign-in depends on site access
and yt-dlp support. Models and transcripts stay outside the application bundle.
