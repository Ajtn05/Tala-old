Features

Built for privacy. Built for speed.

🔒

Completely offline

Runs whisper.cpp locally with GPU acceleration via Apple Metal. Your audio never touches a server.

🎙

Mic + system audio

Capture your microphone, system audio from any app, or both at the same time. Each line is labeled by source so you know what came from where.

📋

Timestamped transcripts

Every session is saved as a clean text file in ~/Documents/Kian/ with timestamps and source labels.

⚡

Optional menu bar controls

Open Tala from the Dock. Enable the menu bar icon in Settings for quick recording controls; it is off by default. Start new recordings and imports through New transcription.

🔧

Guided setup

No virtual audio drivers are needed. Settings checks models and optional media tools before you transcribe.

🌍

Multilingual

Powered by Whisper large-v3-turbo. Automatic language detection for English, Filipino, Taglish, and other supported languages.

Use cases

Who is Tala for?

💻

Meetings and calls

Transcribe Zoom, Google Meet, or any video call in real time. Capture both sides of the conversation with system audio + mic mode. Never miss an action item again.

🎓

Lectures and courses

Record online lectures or YouTube tutorials and get a searchable text transcript. Great for students who want to review material later without re-watching.

🎙️

Podcasts and interviews

Turn podcast episodes or recorded interviews into text. Source labels show what came from the mic vs. system audio when recording both.

✍️

Voice notes and journaling

Think out loud into your mic and let Tala turn it into text. Faster than typing for brainstorms, drafts, and daily journals.

♿

Accessibility

Live captions for any audio playing on your Mac. Useful for the deaf and hard-of-hearing community, or anyone in a noisy environment.

🔐

Sensitive conversations

Legal calls, medical consultations, HR discussions. When privacy matters, Tala keeps everything on your machine. No cloud, no third-party access.

How it works

Up and running in minutes.

01

Install

Install Tala, check optional media tools, then reuse a verified model or download it once in Settings.

02

Grant permissions

Allow microphone access on first launch. System audio capture permission is requested when needed.

03

Record

Choose New transcription → Record live audio, select an audio source, and press Start recording. Tala saves finalized speech locally.

04

Review

Open a session to review, edit, copy, or export it. Choose paragraphs, single-line plain text, timestamps, or source labels.

Getting started

No previous Kian installation needed.

1. Install Tala

Get Tala.dmg from this repository's releases when available, or build from source using the README. Copy Tala.app to ~/Applications and open it. macOS may ask you to approve the ad-hoc signed app in Privacy & Security.

2. Check media tools

New transcription → Import audio or video and Settings check FFmpeg, ffprobe, and yt-dlp. Live recording needs none of these. For files and URLs, install the optional tools with Homebrew, then click Check again.

brew install ffmpeg yt-dlp

3. Prepare the model

Settings reuses a checksum-verified existing model in place. If none is available, choose Download model (1.6 GB). Downloads are stored outside the app in ~/Library/Application Support/Kian/models for compatibility and survive updates.

4. Transcribe in the original language

Leave language detection on Automatic / multilingual for English, Filipino, Taglish, and other supported languages. Record live audio or import a file or supported URL. Grant audio and Documents permissions when requested. Edit, copy, or export the resulting transcript.
